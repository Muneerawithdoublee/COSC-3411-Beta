## Requirements

- PHP
- Bash
- Linux / Kali Linux
- Windows (Optional)

---

## Installation & Run

```bash
sudo apt install php
```

```bash
chmod +x beta-phish.sh
```

```bash
./beta-phish.sh
```

---

## Run Local Server

```bash
chmod +x start-server.sh
```

```bash
./start-server.sh
```

---

## Run on Windows

```bash
"C:\php\php.exe" -S 127.0.0.1:8080
```

Then open:

```text
http://127.0.0.1:8080
```
